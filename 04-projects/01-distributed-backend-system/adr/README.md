# Architecture Decision Records

- Tên file: `NNNN-<slug>.md` (ví dụ `0001-use-outbox-pattern.md`), đánh số tăng dần, không xóa ADR cũ — chỉ đánh dấu *Superseded*.
- ADR do **người học** viết khi ra quyết định thật trong lúc làm project (có thể dùng AI phản biện sau khi đã viết).
