# Weekly Log

Nhật ký học hằng tuần — **do chính người học viết, không dùng AI viết hộ** (ROADMAP §2.2, §2.3).

- Tên file: `YYYY-Wnn.md` (ví dụ `2026-W48.md`), theo ISO week.
- Template: [docs/templates/weekly-log-template.md](../docs/templates/weekly-log-template.md)
- Viết bằng tiếng Anh để luyện TOEIC/technical writing cùng lúc.
- Mỗi quý: tổng hợp vào Quarterly Review (ROADMAP §10).

```
weekly-log/
├── README.md
├── 2026-W48.md
└── 2026-W49.md
```
