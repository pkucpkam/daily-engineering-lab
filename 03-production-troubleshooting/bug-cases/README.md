# Bug Cases

Bug **thật** (từ công việc hoặc từ incident lab) phân tích theo phương pháp khoa học — **người học tự viết**.

- Template: [templates/bug-template.md](./templates/bug-template.md)
- Đặt file trong `content/`, tên `YYYY-MM-DD-<slug>.md`.
- Không đưa dữ liệu/tên hệ thống nhạy cảm của công ty; ẩn danh hóa trước khi commit.
- Bài luyện có sẵn để tái hiện: [../incident-labs/](../incident-labs/README.md)
